ICONS NEEDED
============

The extension requires three icon sizes:
- icon16.png (16x16)
- icon48.png (48x48)
- icon128.png (128x128)

Design:
- Simple, geometric
- Use the Scale brand colors (deep blue #0A1E3D, cyan #00D9FF)
- Symbol suggestion: A simple bar chart or stacked blocks showing scale
- Should work in both light and dark themes

For now, you can:
1. Create simple PNG icons using any image editor
2. Use a placeholder generator
3. Or temporarily remove icon references from manifest.json

The extension will work without icons during development, they're only needed
for production release to the extension stores.
